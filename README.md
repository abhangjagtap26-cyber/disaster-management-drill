# 🚨 Disaster Management Drill — Virtual Disaster Preparedness Platform
> **Smart India Hackathon 2026** | Problem Statement ID: 25008 | **Team Apex**

An interactive, client-side emergency training platform that converts passive safety guidelines into engaging virtual drills for schools and colleges across India.

---

## 🌟 Key Features
* 📍 **Exact GPS Risk Mapping:** Uses device location to auto-prioritize regional disaster vulnerabilities (Flood/Tsunami, Earthquake, or Fire).
* 🎮 **2.5D Interactive Simulation:** Move with WASD/Mouse, inspect emergency hazards, and make life-saving decisions under pressure.
* 🎖️ **Captain Brave Mascot:** Real-time feedback, streak multipliers, and military-grade drill guidance.
* 📊 **Admin / Teacher Dashboard:** Live readiness score tracking and drill analytics via `LocalStorage`.
* 🆘 **Emergency Directory:** Integrated one-tap direct calling to 112, NDMA (1078), and State Relief (1070).

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS, Lucide Icons
* **Graphics & Engine:** Vanilla JavaScript, WebGL (OGL 3D Particle Canvas)
* **Data Persistence:** Client-side `LocalStorage` (Zero server overhead)
* **Deployment:** Hosted live on Netlify
